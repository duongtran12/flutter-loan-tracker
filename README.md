# Flutter Loan Tracker

Ứng dụng Flutter quản lý các lượt cho mượn đồ bằng dữ liệu tạm trong bộ nhớ.

## Chức năng

- Xem danh sách và chi tiết lượt mượn
- Thêm lượt mượn và chọn ảnh từ thư viện
- Sửa thông tin, thay ảnh và cập nhật trạng thái
- Xóa có hộp thoại xác nhận
- Tìm kiếm và lọc theo trạng thái
- Tự nhận biết lượt mượn quá hạn

## Lưu ý

Dữ liệu hiện chưa kết nối cơ sở dữ liệu và sẽ trở về dữ liệu mẫu khi khởi động lại ứng dụng.
